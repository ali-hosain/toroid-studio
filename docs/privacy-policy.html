Privacy Policy

Effective date: September 17, 2026  ·  Developer: Ali Hosain  ·  App: Toroid Studio

Short version: Toroid Studio does not collect, sell, or share your personal data or code. Your files stay on your device or your own cloud accounts. AI calls go directly from your device to Anthropic using your own API key.

1. What We Collect

Toroid Studio collects the minimum data necessary to operate:

  • Nothing by default. The app works fully offline (except AI features) with no account required.
  • Crash reports (optional): If you enable crash reporting in Settings → Privacy, anonymized crash data may be sent to Firebase Crashlytics to help us fix bugs. This data does not include file content, API keys, or any personally identifiable information.
  • Feedback submissions (optional): If you tap "Send Feedback," you may submit a category, description, and optional screenshot. We also attach non-sensitive device metadata: app version, Android version, device model, and enabled runtimes. This never includes file content or API keys. We show you exactly what will be sent before you submit.

2. Your Code and Files

Your source code, project files, and file contents never leave your device except in these two cases you explicitly initiate:

  • AI requests: When you use AI features (chat, inline completion, code review, etc.), relevant code context is sent directly from your device to Anthropic's API using your own API key. We never see this data. Anthropic's privacy policy applies: anthropic.com/privacy
  • Cloud sync (Pro tier): If you enable cloud sync for a project, files are uploaded to your own Google Drive account. We never have access to your Drive or your files.

3. API Keys and Credentials

Your Anthropic API key, Git tokens, and any other credentials you enter are stored exclusively on your device using Android's Keystore system (hardware-backed encrypted storage). They are never transmitted to us, never logged, and never included in crash reports or feedback submissions.

4. Third-Party Services

  • Anthropic API — processes AI requests using your API key. See Anthropic's privacy policy.
  • Google Drive — used for cloud sync if you enable it, under your own Google account.
  • Firebase Crashlytics — anonymized crash reporting, only if enabled in Settings.
  • Netlify — used for deploy if you configure it with your own Netlify token.

5. Children's Privacy

Toroid Studio is a developer tool intended for users aged 13 and older. We do not knowingly collect data from children under 13.

6. Changes to This Policy

We may update this policy as the app evolves. The effective date at the top will always reflect the latest version. For significant changes, we will notify users via an in-app notice.
